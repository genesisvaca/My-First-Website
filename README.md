This repository contains the very first website I built on my own in **2024**. It was a personal learning project to practice **semantic HTML**, **handcrafted CSS** (with a pastel / denim-inspired style), and a bit of **vanilla JavaScript** for interactivity. The goal was to simulate a small online denim brand called **“Sweet Jean”** with several pages: home, collections, store sections, brand story, environmental commitment, login form and a working contact form.

> Even though it was my first project ever, I wanted it to look like a real brand site ✨


## 📋 Overview

“**Sweet Jean**” is a **static website** for a fictional jeans & urban fashion brand.  
It includes:

- A **hero / landing** page with navigation and call-to-action
- **Collections section** (summer, women, men, urban)
- A simple **products layout** for the women’s store
- A **brand page** with an image carousel
- A **sustainability / environment** page
- A **login page** styled with Bootstrap
- A **contact form** connected to Formspree

The whole project was built with **pure HTML, CSS and JS**, without build tools or frameworks, to understand how pages, assets and navigation work together.

<br>

## ✨ Main Features

- 🧭 **Multi-page navigation**: `index.html` links to “About us”, “Our commitment”, “Store”, “Contact”, and login.
  
- 🎯 **Pastel + denim branding**: colors inspired by #40647e, bisque and light blue (same palette as the site).
  
- 🛍️ **Store layout** (`tienda-mujer.html`): product cards, buttons and a search bar with a small JS demo.
  
- 🖼️ **Image carousel** in `quienes-somos.html` powered by a tiny vanilla JS script.
  
- 📝 **Contact form** (`contacto.html`) sending data through **Formspree**.
  
- 🔐 **Login page** (`log-in.html`) using Bootstrap 4, but keeping your brand logo.
  
- 🗺️ **Embedded map** in the footer (Google Maps iframe).
  
- 🧪 **Learning-oriented code**: comments in JS explaining what each line does.

### 🧠 What I Learned (2024)

This project was **the very first website I ever coded** (2023). I built it before starting my formal studies, so the goal was to **understand the basics by doing**:

- how to structure a multi-page site without a framework

- how to keep a consistent navbar and footer across pages

- how to use background images and shadows to make a static site feel “designed”

- how to connect a form to an external service (Formspree) without a backend

- how to mix pure CSS with a Bootstrap page and still keep the same brand

- how to write small, readable JS for UI (the carousel + search alert)

It’s not a perfect project — and that’s the point. It shows the origin of my web developer journey 💛
